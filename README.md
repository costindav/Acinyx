# Acinyx

**Structured Data, Simplified.**

**Acinyx** is a DuckDB-powered desktop application for exploring, transforming, comparing, and processing structured data.

Built around **DuckDB as its core data processing engine**, Acinyx combines the power of analytical SQL with a graphical interface, making complex data operations more accessible without sacrificing flexibility.

From interactive data exploration to reusable transformation pipelines and multi-step workflows, Acinyx provides an integrated environment for working with structured data.

**Current release: v0.1.0-beta — Public Beta for Windows**

## Features

### Data Viewer
Explore structured datasets with interactive filtering, sorting, and basic statistical analysis.

### Data Pipelines
Create, configure, save, load, and execute reusable data transformation pipelines.

### Workflows
Organize multiple pipelines into sequential processing workflows.

### Data Comparison
Compare datasets using the application's dedicated comparison tools.

## Download

Windows portable builds are distributed through [GitHub Releases](https://github.com/costindav/Acinyx/releases).

No separate Python installation is required.

## Getting Started

1. Download the Windows portable ZIP from Releases.
2. Extract the archive into a writable folder.
3. Run `Acinyx_beta_v0.1.exe`.

Do not run the application directly from inside the ZIP archive.

Additional instructions are included in `README_PORTABLE.md` inside the downloadable package.

## Technology

Acinyx is built around **DuckDB**, with Python, PySide6/Qt, pandas, NumPy, and PyArrow.
